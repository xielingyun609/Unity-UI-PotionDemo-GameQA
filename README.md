# Unity-UI-PotionDemo-GameQA
游戏QA作品集项目：Unity简易药水UI交互Demo

## 项目介绍
基于Unity制作UI交互Demo，实现按钮点击文本更新、中英文语言切换。
本人以游戏测试工程师(QA)角度独立完成全套测试工作，用于校招/实习面试作品集。

## 测试内容
✅ UI按钮交互稳定性测试
✅ 多分辨率、窗口全屏自适应兼容性测试
✅ 中英文本地化UI布局测试
✅ Unity编辑器环境 & Windows打包EXE对比测试
✅ 日志查看、冒烟测试、Bug回归验证
